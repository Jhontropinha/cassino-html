# Universo dos Cassinos

Projeto acadêmico desenvolvido para a disciplina de Desenvolvimento Front-End para Web.

## Tema

Cassinos, jogos clássicos e conceitos básicos de probabilidade.

## Objetivo

Apresentar informações educativas sobre jogos tradicionalmente encontrados em cassinos,
utilizando somente HTML e os recursos estudados em aula.

## Estrutura do projeto

- `html/` — páginas HTML
- `img/` — imagens do projeto
- `audio/` — arquivo de áudio local
- `video/` — pasta reservada para vídeo local

## Páginas

1. `index.html` — apresentação do projeto
2. `jogos.html` — roleta, blackjack e poker
3. `probabilidades.html` — tabela com dados reais e informações matemáticas
4. `multimidia.html` — imagens, figure, figcaption e áudio local
5. `contato.html` — formulário avançado

## Recursos utilizados

- `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`
- Navegação fluida entre todas as páginas
- Tabela com `colspan`
- Formulário com `date`, `file`, `range`, `datalist`, `required` e `placeholder`
- `details` e `summary` em mais de uma página
- `figure` e `figcaption` em mais de uma página
- `abbr`, `mark`, `del`, `ins`, `blockquote`, `cite`, `progress` e `meter`
- Áudio local
- `time` com a data da prova
- Comentário HTML de autoria
- Sem CSS e sem JavaScript

## Observação

O projeto possui finalidade acadêmica e informativa. Jogos de azar envolvem risco e não garantem lucro.
